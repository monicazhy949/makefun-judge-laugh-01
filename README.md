A program that writes one original single-line office joke to `/output/entry.txt`.

Entry: "Our AI note-taker now attends more meetings than I do — yesterday it declined my own invite with 'per my last email' and asked me to keep it brief."

Run with `python3 main.py`. See [Make the AI Judge Laugh: the Office Joke Open on make.fun](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232).
